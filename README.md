# VocalMIX

歌ってみた用のボーカルMIXスタジオ。ブラウザで動く単一HTMLのWebアプリです。

## 開き方

- GitHub Pages: https://consulenteidealistas.github.io/VocalMIX/
- または `index.html` をブラウザで開く

開くとデモ曲（オケ＋ボーカル＋ハモリ）が読み込まれた状態で始まるので、そのまま再生・編集・書き出しを試せます。自分の音源はドラッグ＆ドロップで読み込めます。

## 機能

- マルチトラック再生（ループ・シーク・BPM・スナップ）
- 波形クリップの移動／トリム／分割／フェードでタイミング調整
- 5バンド・パラメトリックEQ（ドラッグ編集＋数値入力）
- フルコントロールのコンプレッサー（GRメーター付き）
- リバーブ／ディレイ（インサート＆センド／リターン）、バスルーティング
- ボリューム／パンのオートメーション曲線描画
- 書き出し: WAV／MP3（48kHz・24bit対応）

ピッチ補正は内蔵していません。Melodyne等で補正済みのWAVを読み込むワークフローを想定しています。
